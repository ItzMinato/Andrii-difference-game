# Spot The Difference Game

Interactive browser game made with HTML, CSS and JavaScript.

## About
This project is a modern web-based "Spot The Difference" game where players must find hidden differences between two images before the timer runs out.

The game includes:
- 3 unique levels
- timer system
- animated UI
- level progression
- responsive design
- visual effects and glowing interface

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Features
- Fully client-side project
- No backend or server required
- Works directly in the browser
- Modern gaming-style interface
- Interactive gameplay
